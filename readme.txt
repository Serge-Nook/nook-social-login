Registration and login via VK ID, Steam, Battle.net, Yandex ID, Google, Twitch and Discord.

== Description ==

Adds social login buttons to the WordPress login and registration forms, the comment form, WooCommerce forms and the [nook_social_login] shortcode.

* New accounts on first login (optional), e-mail prompt when the network does not share it.
* Link and unlink networks in the user profile.
* Social avatars.
* OAuth state bound to the browser, PKCE for VK ID and Google, server-side Steam OpenID verification.
* Russian, English and Chinese (Simplified).

Author: Горшков Сергей Владимирович — https://nookbat.ru/

== Installation ==

1. Upload the zip in Plugins → Add New → Upload Plugin and activate it.
2. Open Settings → Social Login, enable networks and paste the application keys. Use the Redirect URL shown on each card.
